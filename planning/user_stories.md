# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

Reader: a user who can view a reading list, add to it, and earn reading achievements

## Draft User Stories


1. As a reader, I want to create an account, so that I can have access to my own private reading list.

2. As a reader, I want to create a list of books I want to read, so that I can keep track of my books in one place.

3. As a reader, I want to update my list of books, so that I can add/delete books whenever. 

4. As a reader, I want to filter and sort my list by status, genre, or length, so that I can pick what to read next.

5. As a reader, I want to update the status of each book, so that I can keep track if either I haven't started reading, am currently reading, or have finished reading it.

6. As a reader, I want to see my list of completed books, so that I can look back at my progress.

7. As a reader, I want to be rewarded for finishing a book, so that I continue to feel motivated to read books.

8. As a reader, I want to see a list of my achievements, so that I can see how much more of an experienced reader I am becoming.

9. As a reader, I want to see all achievements, including locked ones, so that I have goals to work toward.

10. As a reader, I want to see stats like total pages read and number of genres read, so that I can understand my reading habits and see how close I am to my next achievement.
